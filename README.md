## Usage
```
lapptex <input.tex|input.typ|input_dir> [output.html|-o output.html] [options]
```

```bash
curl https://arxiv.org/src/2411.19826v1 -o 2411.19826v1.tar.gz
mkdir 2411.19826v1 && tar -zxvf 2411.19826v1.tar.gz -C 2411.19826v1
lapptex 2411.19826v1
start 2411.19826v1/main.html
```
